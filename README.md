### pyrulearn has moved

The public version of **pyrulearn**, a general modular rule learning framework, is now at
**[github.com/FAW-JKU/pyrulearn](https://github.com/FAW-JKU/pyrulearn)**.
Old links to `juffif/pyrulearn` redirect there; please use the new address for
cloning, `pip install git+https://github.com/FAW-JKU/pyrulearn.git`, issues and citations.
